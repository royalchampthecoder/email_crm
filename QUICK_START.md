# 🚀 Quick Start Guide

## Welcome to Your New Modern Email CRM!

Your Email CRM has been completely redesigned. Here's how to get started immediately:

---

## 🎯 First Time Setup

### 1. **Open the Dashboard**
- Navigate to `dashboard.php`
- You'll see the modern design automatically
- Try clicking the moon icon 🌙 in the top-right to toggle dark mode

### 2. **Create Your First Template**
- Go to **Templates** page
- Click **"Add Template"** button
- Fill in the form:
  - **Title**: Template name (e.g., "Python Developer")
  - **Company**: Company name
  - **Position**: Job position
  - **Subject**: Email subject line
  - **Body**: Write your email (use the rich text editor)
- Click **"Save Template"**

### 3. **Send Your First Email**
- Go to **Dashboard** or any page
- Click **"Send Email"** button (top-right)
- Select a template from the dropdowns
- Enter recipient email
- Click **"Send Email & Open Outlook"**
- The email will be tracked and Outlook will open with pre-filled data

### 4. **View Sent Emails**
- Go to **Sent Emails** page
- You'll see all emails sent with filters and search
- Try the search, company filter, or status filter
- Click **"Export CSV"** to download data

## 🎯 Common Tasks

3. Modify the fields
4. Click **Save Template**

1. Go to **Templates**

1. Go to **Templates**

### How to Filter Sent Emails

## 🐛 Troubleshooting

### Dark Mode Not Working?
- Clear browser cache
- Check if localStorage is enabled
- Try a different browser

### Forms Not Validating?
- Ensure all required fields are filled (marked with *)
- Check if JavaScript is enabled

### Charts Not Showing?
- Wait for data to load (look for loading animation)
- Check if you have sent emails
- Refresh the page

### Mobile Menu Not Working?
- Click the hamburger icon at bottom-right
- Check if JavaScript is enabled
- Try a different browser

### Emails Not Saving?
- Check internet connection
- Ensure all fields are filled
- Check browser console (F12) for errors
